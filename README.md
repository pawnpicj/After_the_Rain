# After the Rain

เกมยิงมุมมองบุคคลที่สามในบรรยากาศอาชญากรรมกลางฝน เลือก **Logan Wolf** หรือ **Megan Wolf** เป็นตำรวจนอกเครื่องแบบ แล้วตามหลักฐานคดีฆาตกรรมพ่อแม่ผ่านท่าเรือ คลังสินค้า และสถานีสูบน้ำ อ่าน [บทและเรื่องย่อรายด่าน](STORY.md)

เคลียร์พื้นที่แล้วเข้าหาจุดไฟเขียวเพื่อกด **E** หน้าสรุประหว่างด่านจะบอกสิ่งที่พบและเบาะแสถัดไป การเริ่มด่านใหม่จะเติมพลังชีวิต เกจสโลว์เวลา และกระสุน

## เปิดเล่นบน Windows

ดาวน์โหลด `After-the-Rain-Windows-x64.zip` จาก [GitHub Releases](https://github.com/pawnpicj/After_the_Rain/releases/latest) แล้วแตกไฟล์และดับเบิลคลิก `After the Rain.exe` ภายในโฟลเดอร์ที่แตกออกมา เกมเปิดแบบเต็มจอและเล่นออฟไลน์ได้ เก็บไฟล์ในโฟลเดอร์โปรแกรมไว้ด้วยกัน

- กด **F11** เพื่อสลับระหว่างเต็มจอกับโหมดหน้าต่าง
- กด **Esc** เพื่อหยุดเกม แล้วเลือก **ออกจากเกม** หรือกด **Alt+F4** เพื่อปิดโปรแกรม

## เปิดเล่นในเบราว์เซอร์

เปิดไฟล์ `index.html` ด้วย Chrome หรือ Edge บนเดสก์ท็อป แล้วกด **เริ่มภารกิจ** เกมใช้ WebGL 2 และเปิดจากไฟล์ในเครื่องได้โดยไม่ต้องรันเซิร์ฟเวอร์ เก็บโฟลเดอร์ `dist` และไฟล์ `style.css` ไว้ข้าง `index.html`

ใช้ปุ่ม **เต็มจอ** ที่หน้าเมนูหรือหน้าหยุดเกมเพื่อสลับโหมดการแสดงผล

| ปุ่ม | การควบคุม |
| --- | --- |
| W A S D | เคลื่อนที่ |
| เมาส์ / คลิกซ้าย | เล็ง / ยิง |
| Shift ค้าง | สโลว์เวลาและใช้พลังจากเกจ |
| Space | พุ่งไปตามทิศที่กด หรือพุ่งไปข้างหน้าขณะยืน สามารถยิงระหว่างพุ่งได้ |
| R | บรรจุกระสุน |
| E | เปิดประตูท่าเรือ เก็บหลักฐาน หรือเริ่มส่งข้อมูลที่จุดไฟเขียว |
| Esc | หยุดเกม |

เกจสโลว์เวลาฟื้นเมื่อพักจากการใช้งานหรือเมื่อกำจัดศัตรู หากเบราว์เซอร์จับเมาส์ไม่ได้ ให้กดเมาส์ขวาค้างแล้วลากเพื่อเล็ง

## แก้ไขซอร์ส

ใช้ Node.js และ npm ภายในโฟลเดอร์โปรเจกต์

```powershell
npm install
npm run build
```

ใช้ `npm run desktop` เพื่อเปิดเกมด้วย Electron ระหว่างพัฒนา และ `npm run build:windows` เพื่อสร้างโฟลเดอร์ Windows x64 ใน `release`

ข้อมูลด่านและข้อความระหว่างด่านอยู่ใน `src/campaign.js` ฉากและโมเดลศัตรูอยู่ใน `src/world.js` โมเดลผู้เล่นอยู่ใน `src/player-model.js` ส่วนการควบคุม AI และกติกาภารกิจอยู่ใน `src/game.js`
